# Работа с V8:Pulsar

V8:Pulsar предоставляет агенту MCP-инструменты для наблюдения за сеансами 1С, работы с окнами, снимками и проверяемыми пользовательскими сценариями.

## Безопасный порядок

1. Сначала получить список сеансов и определить точную цель по идентификатору процесса, пути запуска и роли сеанса.
2. Для чтения использовать самый узкий подходящий инструмент V8:Pulsar.
3. Перед действием прочитать живую схему инструмента. Не восстанавливать названия параметров по памяти.
4. После запуска, перехода, открытия или закрытия формы заново прочитать состояние, от которого зависит следующий шаг.
5. Проверить пользовательский эффект: успешная доставка команды сама по себе не доказывает результат.

## Границы действий

- Не выбирать сеанс только по заголовку окна.
- Не закрывать и не перезапускать процесс, пока не подтверждено, что он относится к текущей задаче.
- Не повторять автоматически клик, ввод или другую команду, если результат обозначен как доставленный, но не подтверждённый.
- Для управляемого тестового сеанса предпочитать инструменты TestClient.
- Для Конфигуратора и сценариев без подходящего API TestClient использовать UI Automation или Win32 после чтения актуального дерева окна.
- Перед реальным вводом, сменой активного окна, действиями по экранным координатам или снимком всего рабочего стола предупредить пользователя и получить разрешение на использование видимого рабочего стола.

## Проверка результата

- Запуск и закрытие подтверждать новым списком сеансов.
- Действие в TestClient подтверждать новым состоянием формы.
- Действие через UI Automation подтверждать новым деревом, снимком или разницей снимков.
- При структурной ошибке читать её код и предлагаемое действие. Не повторять тот же вызов с теми же параметрами при неизменном состоянии.
- Если инструмент V8:Pulsar должен работать, но возвращает противоречивый результат, остановить этот сценарий и сообщить пользователю о сбое инструмента.

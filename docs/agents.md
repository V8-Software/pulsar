# Настройка ИИ-агентов

Агенту нужны две части: подключение к MCP-серверу V8:Pulsar и правила безопасной работы с сеансами 1С.

## Подключение MCP

Скопируйте файл [`configs/.mcp.json`](../configs/.mcp.json) в корень проекта, если ваш клиент поддерживает этот формат. Если в проекте уже есть такой файл, добавьте в существующий объект `mcpServers` только запись `v8-pulsar`.

Не заменяйте весь существующий файл образцом: в нём могут находиться другие нужные серверы.

## Правила проекта

Файл [`configs/AGENTS.md`](../configs/AGENTS.md) — готовый безопасный минимум для проекта, в котором агент работает с 1С через V8:Pulsar.

Если в проекте уже есть `AGENTS.md`, перенесите только относящийся к V8:Pulsar раздел. Сохраните собственные правила проекта и не затирайте их образцом.

## Установка навыков

Доступны два дополняющих друг друга навыка:

- [`testing-start`](../skills/testing-start/SKILL.md) — подготавливает TestClient, TestManager и справочник API перед автоматизированным тестированием форм 1С;
- [`v8-gui-validation`](../skills/v8-gui-validation/SKILL.md) — задаёт проверяемый порядок для многошаговых сценариев в интерфейсе Windows и 1С.

Для Codex скопируйте нужные каталоги навыков в:

```text
%USERPROFILE%\.codex\skills\<имя-навыка>
```

Для среды, которая ищет общие навыки агентов, используйте:

```text
%USERPROFILE%\.agents\skills\<имя-навыка>
```

После копирования перезапустите или обновите список навыков в используемом агенте.

## Безопасность

- Всегда выбирайте сеанс по идентификатору процесса и роли, а не только по заголовку окна.
- Не закрывайте и не перезапускайте сеанс, пока не подтверждено, что он относится к текущей задаче.
- Не повторяйте действие автоматически, если команда доставлена, но пользовательский эффект не подтверждён.
- Перед вводом с клавиатуры, перемещением мыши или сменой активного окна предупреждайте пользователя: такие действия используют общий рабочий стол.

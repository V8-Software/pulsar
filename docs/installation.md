# Установка V8:Pulsar

V8:Pulsar устанавливается на 64-разрядную Windows и после запуска предоставляет локальный MCP-сервер для ИИ-агентов.

## Установка

1. Откройте [последний выпуск](https://github.com/V8-Software/pulsar/releases/latest).
2. Скачайте файл установщика с окончанием `win-x64-setup.exe`.
3. При необходимости проверьте контрольную сумму файла по значению SHA-256 на странице выпуска.
4. Запустите установщик и следуйте его указаниям.
5. Запустите V8:Pulsar.

## Проверка контрольной суммы

Откройте PowerShell в каталоге со скачанным файлом и выполните:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\v8-pulsar-<версия>-win-x64-setup.exe'
```

Полученное значение должно полностью совпасть со значением SHA-256 на странице выпуска.

## Проверка MCP

Стандартный адрес локального сервера:

```text
http://localhost:8010/mcp
```

Скопируйте [готовый образец `.mcp.json`](../configs/.mcp.json) в корень своего проекта или перенесите из него настройку `v8-pulsar` в конфигурацию используемого MCP-клиента.

Если клиент не подключается, сначала убедитесь, что V8:Pulsar запущен. Затем проверьте, не занят ли порт `8010` другой программой и не переопределён ли адрес сервера в настройках V8:Pulsar.

# Тестовый стенд V8:Pulsar

Стенд открывает в браузере простой интерфейс для ручного вызова MCP-инструментов V8:Pulsar. Он показывает исходный ответ сервера и позволяет открыть снимки, пути к которым вернул инструмент.

Стенд работает локально: HTTP-сервер принимает подключения только на `localhost:7100`, а V8:Pulsar запускается в режиме `--mcp` по стандартному вводу и выводу.

## Требования

- Windows;
- установленный V8:Pulsar;
- Python 3.10 или новее без дополнительных пакетов.

## Запуск

Укажите путь к установленному Пульсару, если `v8-pulsar.exe` отсутствует в `PATH` и стандартных каталогах установки:

```powershell
$env:V8_PULSAR_EXE = 'C:\Program Files\V8Pulsar\v8-pulsar.exe'
```

Затем запустите:

```powershell
python .\server.py
```

Откройте [http://localhost:7100](http://localhost:7100). В Windows также можно запустить `Открыть стенд.bat` или `Открыть стенд.vbs`.

## Проверка

```powershell
python -m unittest -v test_server.py
```

Тесты проверяют восстановление соединения с MCP-процессом, поиск `v8-pulsar.exe` и безопасную выдачу снимков по непрозрачным локальным ссылкам.

## Ограничения

- Стенд предназначен для локальной диагностики, а не для размещения в сети.
- Поле аргументов передаётся выбранному MCP-инструменту как JSON.
- Сервер выдаёт только PNG-файлы, пути к которым явно присутствуют в ответе V8:Pulsar.
